# CineReview - Sentiment Analysis Web App

![CineReview Demo](https://raw.githubusercontent.com/therayyanshariff/CineReview/main/demo.png)

A web application built with Streamlit that uses a machine learning model to perform sentiment analysis on movie reviews. This project demonstrates the end-to-end process of building an interactive ML application, from data preprocessing to a final, styled user interface.

## ✨ Features

-   **Sentiment Prediction:** Classifies text as either 'Positive' or 'Negative' using a trained Logistic Regression model.
-   **Dynamic UI:** Features animated columns of images that scroll in opposite directions for a visually engaging experience.
-   **Custom Styling:** A custom, elegant UI with a sophisticated color scheme and typography, inspired by editorial design.
-   **Interactive:** Users can input any text they want for real-time analysis.

## 🛠️ Technologies Used

-   **Backend:** Python
-   **Web Framework:** Streamlit
-   **Machine Learning:** Scikit-learn
-   **NLP:** NLTK (Natural Language Toolkit)
-   **Styling:** Custom CSS

## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/therayyanshariff/CineReview.git
    cd cinereview-app
    ```

2.  **Install the required libraries:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Streamlit app:**
    ```bash
    streamlit run app.py
    ```
